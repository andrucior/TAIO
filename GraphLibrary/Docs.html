Overview

GraphLibrary.Model provides a generic, feature-rich implementation of graph data structures in C#. It supports both directed and undirected graphs, weighted edges, and includes common graph algorithms.

Features

  • Generic implementation - works with any non-nullable type
  • Support for both directed and undirected graphs
  • Weighted edges
  • Comprehensive graph algorithms (BFS, DFS, Dijkstra, etc.)
  • Cycle detection
  • Topological sorting
  • Connected components analysis
  • Path finding utilities

Getting Started

Creating a Graph

// Create an undirected graph
var graph = new Graph<string>();
// Create a directed graph
var directedGraph = new Graph<int>(directed: true);
// Create a copy of an existing graph
var graphCopy = new Graph<string>(graph);

Adding Vertices and Edges

var graph = new Graph<string>();
// Add vertices
graph.AddVertex("A");
graph.AddVertex("B");
graph.AddVertex("C");
// Add edges (automatically adds vertices if they don't exist)
graph.AddEdge("A", "B");
graph.AddEdge("B", "C", weight: 2.5);
graph.AddEdge("A", "C", weight: 1.0);

Edge<T> Class

Represents an edge in the graph with source, destination, weight, and direction information.

Constructor

Edge(T from, T to, double weight = 1.0, bool isDirected = false)

Parameters:

  • from - Source vertex
  • to - Destination vertex
  • weight - Edge weight (default: 1.0)
  • isDirected - Whether the edge is directed (default: false)

Properties

Property Type Description
From T Source vertex (immutable)
To T Destination vertex (immutable)
Weight double Edge weight (immutable)
IsDirected bool Direction indicator (immutable)

Example Usage

var edge1 = new Edge<string>("A", "B");
var edge2 = new Edge<int>(1, 2, weight: 5.0, isDirected: true);
Console.WriteLine(edge1); // Output: A <-> B
Console.WriteLine(edge2); // Output: 1 -> 2 (weight: 5)

Graph<T> Class

Properties

Vertex Operations

AddVertex

void AddVertex(T v)

Adds a vertex to the graph. Does nothing if vertex already exists.

graph.AddVertex("A");

RemoveVertex

bool RemoveVertex(T v)

Removes a vertex and all edges connected to it. Returns true if successful.

bool removed = graph.RemoveVertex("A");

ContainsVertex

bool ContainsVertex(T v)

Checks if a vertex exists in the graph.

if (graph.ContainsVertex("A")) { Console.WriteLine("Vertex A exists"); }

Edge Operations

AddEdge

void AddEdge(T u, T v, double weight = 1.0)

Adds an edge between two vertices. Creates vertices if they don't exist. Prevents duplicate edges.

graph.AddEdge("A", "B"); graph.AddEdge("B", "C", weight: 3.5);

RemoveEdge

bool RemoveEdge(T u, T v)

Removes an edge between two vertices. Returns true if successful.

graph.RemoveEdge("A", "B");

RemoveEdge

bool RemoveEdge(Edge e)

Removes an edge from e.From to e.To. Returns true if successful.

HasEdge

bool HasEdge(T u, T v)

Checks if an edge exists between two vertices.

if (graph.HasEdge("A", "B")) { Console.WriteLine("Edge exists"); }

GetEdgeWeight

double? GetEdgeWeight(T u, T v)

Returns the weight of an edge, or null if the edge doesn't exist.

var weight = graph.GetEdgeWeight("A", "B"); if (weight.HasValue) { Console.WriteLine($"Weight: {weight.Value}"); }

Graph Analysis

Degree / InDegree / OutDegree

int Degree(T v) int InDegree(T v) int OutDegree(T v)

Returns the degree of a vertex. For directed graphs, InDegree counts incoming edges and OutDegree counts outgoing edges.

int degree = graph.Degree("A"); int inDegree = graph.InDegree("A"); int outDegree = graph.OutDegree("A");

GetNeighbors

IEnumerable<(T neighbor, double weight)> GetNeighbors(T v)

Returns all neighbors of a vertex with their edge weights.

foreach (var (neighbor, weight) in graph.GetNeighbors("A"))
{
Console.WriteLine($"Neighbor: {neighbor}, Weight: {weight}");
}

GetAllEdges

IEnumerable<Edge<T>> GetAllEdges()

Returns all edges in the graph.

foreach (var edge in graph.GetAllEdges()) { Console.WriteLine(edge); }

Algorithms

Traversal Algorithms

BFS (Breadth-First Search)

List<T> BFS(T start)

Performs a breadth-first traversal starting from a given vertex.

var visited = graph.BFS("A"); Console.WriteLine(string.Join(" -> ", visited));

DFS (Depth-First Search)

List<T> DFS(T start)

Performs a depth-first traversal starting from a given vertex.

var visited = graph.DFS("A"); Console.WriteLine(string.Join(" -> ", visited));

Shortest Path Algorithms

Dijkstra

Dictionary<T, double> Dijkstra(T source)

Computes shortest distances from source to all other vertices using Dijkstra's algorithm.

var distances = graph.Dijkstra("A");
foreach (var (vertex, dist) in distances) {
Console.WriteLine($"Distance to {vertex}: {dist}");
}

GetShortestPath

List<T>? GetShortestPath(T source, T target)

Finds the shortest path between two vertices. Returns null if no path exists.

var path = graph.GetShortestPath("A", "D");
if (path != null) {
Console.WriteLine($"Path: {string.Join(" -> ", path)}");
} else {
Console.WriteLine("No path exists");
}

Cycle Detection

HasCycle

bool HasCycle()

Detects if the graph contains a cycle. Works for both directed and undirected graphs.

if (graph.HasCycle()) { Console.WriteLine("Graph contains a cycle"); }

Topological Sort

TopologicalSort

List<T>? TopologicalSort()

Performs a topological sort on a directed acyclic graph. Returns null if the graph contains a cycle.

Note: Throws InvalidOperationException for undirected graphs.
var sorted = directedGraph.TopologicalSort();
if (sorted != null) {
Console.WriteLine($"Topological order: {string.Join(" -> ", sorted)}");
} else Console.WriteLine("Graph contains a cycle");

Connectivity

IsConnected

bool IsConnected()

Checks if all vertices in the graph are reachable from each other.

if (graph.IsConnected()) { Console.WriteLine("Graph is connected"); }

GetConnectedComponents

List<List<T>> GetConnectedComponents()

Returns all connected components in the graph.

var components = graph.GetConnectedComponents();
for (int i = 0; i < components.Count; i++) {
Console.WriteLine($"Component {i + 1}: {string.Join(", ", components[i])}");
}

Utility Methods

GetTranspose

Graph<T> GetTranspose()

Returns a new graph with all edges reversed. Only for directed graphs.

var transposed = directedGraph.GetTranspose();

Clear

void Clear()

Removes all vertices and edges from the graph.

graph.Clear();
